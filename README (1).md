
# 🏥 Clinic On Screen – Superspeciality OPD Clinic Website

Clinic On Screen is a responsive and modern healthcare website designed for a superspeciality OPD clinic.  
The project is built using **HTML, CSS, JavaScript, and PHP**, focusing on clean UI, easy navigation, and patient-friendly interaction.

---

## 🚀 Features

- Responsive and modern UI design
- Home, About, Services, Departments, Doctors, Blog, and Contact pages
- Appointment call-to-action buttons
- Department-wise service pages
- Blog section with sidebar (search, tags, popular posts)
- Clean navigation bar with dropdown menus
- PHP-ready structure for backend integration

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Backend:** PHP  
- **Design:** Responsive layout, reusable components  
- **Local Server:** XAMPP / WAMP / PHP built-in server

## ⚙️ How to Run the Project

1. Install **XAMPP** or **WAMP**
2. Copy the project folder into:
   ```
   htdocs (XAMPP) OR www (WAMP)
   ```
3. Start **Apache Server**
4. Open browser and visit:
   ```
   http://localhost/clinic-on-screen/
   ```
